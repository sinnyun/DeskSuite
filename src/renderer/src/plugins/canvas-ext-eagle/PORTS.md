# canvas-ext-eagle

- Metadata: canvas / ext / eagle; entry index.tsx; optional renderer plugin. Consumes optional canvas renderer service and eagleLinks IPC; no cross-plugin file imports, host modifications, browser persistence, media copies or standalone MCP.
- Registers lifecycle-owned generic canvas extension points: inspector eagle (EagleInspector), resource enricher eagle and external-link resolver eagle. Disposal removes all contributions. Missing canvas disables this plugin; missing main capability surfaces an error for Eagle actions.
- Disk-backed Eagle drags use the existing dropImport -> import -> unified resource chain; the enricher calls eagleLinks.inspect, snapshots metadata in the main plugin, and initializes a node name (300 chars) and tags (50 x 100 chars). Scene stores only the unified URI and ordinary node fields. No Eagle-specific scene schema or base64 data.
- Resolver accepts only eagle://item/<alphanumeric-id> (optional trailing slash), no credentials/query/fragment/port. Other schemes are ignored so other plugins can handle them. Main link resolves and registers the original then returns its unified URI to normal import. Does not fetch remote web images.
- Inspector for selected image reads cached source: Eagle name/ID/folders/tags/size/dimensions/rating/annotation/source URL, expandable original/resource/thumbnail/API paths, copy actions (clipboard.writeText), refresh, and locate in Eagle. UI is Chinese, uses SDK ui primitives and internal scrolling supplied by whiteboard. Error messages use the shared bounded, credential/path-scrubbing SDK formatter before entering local component state. Never navigates arbitrary metadata URLs. Reads eagleLinks:changed to refresh, cleans listener on unmount.
- Commands through whiteboard_panel: eagleInspect({id?,reference?,refresh?}) -> metadata|null; eagleOpen({id?,reference?}) -> dispatch result. Default selected node; no source fails clearly. Inspector refresh/open use the same main IPC operations. Host inspector({tab:'properties'}) selects the property tab for MCP validation.
