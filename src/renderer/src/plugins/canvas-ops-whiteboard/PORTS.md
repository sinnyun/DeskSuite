# canvas-ops-whiteboard

- Native text editing is reflected by Snapshot.textEditing and the editing save badge until close/commit; it is transient UI state.

- Incremental synchronization: immutable node/array identity gates node passes; view/selection/save-only notifications do not serialize or scan all nodes. Geometry/style/metadata patch compatible instances (including native Text, shapes, cards/video/frame). Type/collapse, image source or plain/HTML representation changes may recreate a node. Unchanged image leases survive. renderState.sync exposes counters; nodeInstances exposes id/instance/tag/parent/text, and groups exposes native container identity/parent/open/rotation/scale.
- Plain text and notes use a native Text and official TextEditor 2.3.2. textEdit({id?,action:'open'|'set'|'close'|'inspect',text?}) drives the real inner editor; open/set MCP calls must use deferSave:true because ordinary command flush commits editing. Native close saves one history transaction. commitEditing closes only TextEditor before persistence; it does not close image cropping. Composition/229 key events are isolated from plugin Enter/Escape shortcuts. Text is limited to 100,000 characters. richText is an explicit compatible HTML mode.
- Native grouping commands: nativeGroup/nativeUngroup use Editor.group/ungroup; groupEdit({id,open?,select?}) opens/closes/selects real containers; deepSelect({ids}) opens ancestors and selects leaves; activateSelection opens the appropriate text/content editor. Group geometry and leaf board-space geometry persist using Leafer Matrix/dropTo. Groups remain native after transforms, preserving control-frame direction. Flat legacy group IDs remain supported; nested groups round-trip through scene.groups. Layer rows show nested groups and support selecting/entering them.

- MCP commands accept deferSave:true to retain the UI save debounce; default commands still flush before reply. Opening loads the board before revealing the panel, preventing its auto-open effect from queuing a second stale navigation.

- Viewport sizing: the Leafer mount has explicit inline absolute positioning/inset so library DOM initialization cannot override its CSS class to relative. App initial size and ResizeObserver use the visible viewport (not canvas-derived mount content); repeated equal sizes are skipped. renderState.viewport/rendererSize expose the size invariant, and high-DPI backing canvases retain the native pixel ratio. The viewport's minimap size state avoids equal-size React updates; focusing the canvas uses preventScroll.
- profileMove({steps?:10..120=60,dx?:number=1,dy?:number=0,effects?:'current'|'opaque'}) runs actual Editor.move calls over rAF frames and commits one history transaction. Requires selected nodes and no active inner editor. Returns editor CPU, tree draw, read-only hit-test and rAF interval percentiles, coordinate deviation and scene updates during movement. The optional opaque comparison temporarily disables backdrop filters and restores them in finally; production appearance is unchanged. This measures the semantic move/render path, not hardware pointer-to-display latency; snapping may intentionally offset the path. No DOM input events are dispatched.

- Image synchronization preserves the ClipImage instance, its child and decoded-resource lease when the source URI is unchanged and the image stays expanded. Movement, resize, rotation, flip, metadata/style/lock changes, crop commits and history update those objects in place; source/type/collapse/removal still rebuilds or disposes as required. Native transforms of cropped images persist the actual child transform with the frame in the same transaction. renderState.imageNodes exposes transient {id,instance,layer,lease,ready} diagnostics for MCP stability assertions; these IDs are not scene data.
- Layer thumbnails re-check node ownership/editing/readiness after waiting for resource loads and use Leafer syncExport for the small preview. This avoids async export tasks waiting forever for a destroyed board's completed frame and blocking later PNG/JPEG exports.

- Selected-node properties render optional canvas.getInspectors() contributions; no source-provider UI is embedded here. inspector({tab:'layers'|'properties'}) opens a tab via the same state used by UI controls. Unknown external URI-list schemes are passed as links to optional canvas resolvers; no remote content is downloaded by the viewport.
- file:// URI drops also support Windows UNC host/share paths. Unified resources validates the decoded ordinary file path and canonicalizes mapped/UNC aliases; the viewport never reads source bytes.

- Crop commit ownership: pointer/drag completion skips generic transform saves while inner editing or a crop commit is pending. The END handler captures frame and child-image geometry synchronously, then persists one transaction after editor unload. Deferred commits are discarded when the board or node instance changes; source pixels and plugin crop math stay unchanged.

- Metadata: canvas / ops / whiteboard; entry index.tsx; version 2.0.0. Contributions sidebar.activity and floating.panels, panel ID whiteboard; initial 1120x760, minimum 820x560, internal scrolling. Chinese UI, UI primitives from SDK ui service.
- Consumes optional canvas and resources renderer services. Missing canvas hides the panel; missing editing/import commands report capability unavailable. No imports across plugins, no host changes/browser domain storage.
- LeaferJS 2.3.2 + official editor/export/viewport/view/arrow 2.3.2 + leafer-x-ruler 2.0.1 + leafer-x-clip-resize-inner-editor 1.10.0 + leafer-x-easy-snap 1.11.0. Core scene stays independent of engine JSON and temporary runtime URLs. engine.ts owns App/tree/sky, selection/editor transforms, plugin-managed alignment snapping and ruler ticks, proportional corner resize, image node/lease lifetime, video frame canvas, view plugin commands, scene view synchronization and export. Arrow nodes use official `@leafer-in/arrow`; ordinary line nodes remain Leafer paths. `leafer-x-ruler` owns scale ticks and selected-object highlights; React keeps only pointer zones and preview/persisted guide overlays. Persistent ruler guides are represented as invisible Leafer snap targets in the tree; the snap instance is disabled and disposed with the engine. Disposal destroys tree before releasing resource leases. Never destroys global Resource manager.
- Leafer's design viewport type supplies wheel/touchpad pan, Ctrl/Meta-wheel zoom, space/middle-button drag pan and zoom bounds; Leafer's view plugin supplies fit/zoom. The engine zoomLayer is the camera source, and its position/scale changes persist to scene.view so React overlays, minimap, drop coordinates, bookmarks and restart restoration share the same view. React owns multi/box selection, shortcuts (Ctrl/Cmd C/V/D/A/Z/Y, Shift-Z, Delete, Escape), grid/dots, draggable ruler guides, minimap, bookmarks and resource drop/paste. Native clipboard image paste and internal node clipboard are separate. Explorer list/grid/gallery drags arrive as native OS file drops (`Files`); the custom application/x-desksuite-files payload remains supported for other producers.
- Drop priority: application/x-desksuite-files JSON path array, native disk-backed File list, then text/uri-list (local file:// or registered desksuite-resource://; comments and percent-encoded names supported). Native files register through resources.registerFile and the existing bridge's File argument adapter; memory-only files and remote URLs fail without a base64 fallback. Highlight while dragging, reset on leave/drop/dragend/blur/board switch. dropImport({paths?,payload?,uriList?,clientX,clientY}) is the MCP-accessible semantic entry shared with onDrop; native files are in-process UI arguments only. Uses current viewport geometry/view to convert the drop point, finishes any active crop first, and imports one deduplicated batch with 32-unit offsets and preserved image aspect ratios. Source files remain linked originals.
- Text/note content editing supports bold/italic/underline/color and unordered/ordered lists; sanitized subset, backed by plain-text search and a Leafer run layout for static rendering/export. Official `@leafer-in/html` was evaluated but is not installed: HTMLText measures unconstrained natural content and renders it as an image; assigning the fixed node width would scale that image and break current wrapping. Browser contenteditable editing; saved on input/blur through canvas.edit. Images are `ClipImage` nodes cropped by the library's inner editor: double-click or `cropOpen` enters it, the clip window can be moved/resized/rotated/stretched, and exiting writes one undo transaction. Persisted `node.clip` stores the plugin's child-image transform in node-local Leafer units (`clipSpace: leafer-local`); old node-box-normalized clips and `node.crop` are converted when loaded. Source bytes are untouched. Frame membership is logical and grouping expands selection.
- Video is decoded from versioned custom resource URL via native HTMLVideoElement (CORS enabled). Native controls are interactive in content mode; current frames are drawn to Leafer Canvas so canvas mode respects z-order and PNG/JPEG includes the current frame. No video state mutation is recorded in scene history; reading-position memory is deferred. Missing assets show placeholders. Format compatibility depends on Electron codecs.
- Registered viewport commands: fit({selection?}), zoom({value}), transform({dx?,dy?,scale?,angle?}) through actual Leafer editor, select({ids}) sets the canvas selection, export({format:png|jpeg,download?:boolean=true}) -> {format,width,height,data:dataURL}, renderState() -> engine/nodes/images/width/height/cropEditing, thumbnail({id,size?:number=48}) -> transparent PNG dataURL of a single node for the layer panel. Crop commands: cropOpen() -> boolean (enters the inner editor for the single selected unlocked image; toggles off when already editing), cropClose() -> boolean, cropState({id?}) -> {editing,id,box,layer,clip} in node-local Leafer units, cropResize({width,height,lockRatio?}) and cropRatio({ratio:'16:9'}) require active inner editing and return the new state, cropReset() restores the entry crop geometry through the library reset while editing. Only Escape is honored while cropping. Internal videoFrame({id,video:HTMLVideoElement}) redraws without changing persisted state. media({id?,action:inspect|play|pause|seek|volume,time?,value?}) -> native player state. Viewport commands exist only while mounted. Static export waits for current image loads, uses 2x resolution, rejects excessive area/dimensions; excludes editor/rulers/grid/minimap/controls and future DOM viewers without a canvas representation.
- IPC whiteboard.complete acknowledges broadcast whiteboard:action. Panel actions open/replace/flush/inspect/command; new/removeBoard handled by panel, other commands delegated to canvas. MCP acceptance is through whiteboard_panel; no DOM event automation.
- Old Excalidraw scenes are preserved separately and not converted. PDF/Markdown/TXT currently get file cards, with reader extensions deliberately deferred per approved selection. canvas.registerContent(kind,Component) allows future reader plugins without importing this plugin.
- Resource refresh is on load/reopen, not a watcher. Original moved/deleted sources retain stable identities but become unavailable.
